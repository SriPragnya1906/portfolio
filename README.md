# Sri Pragnya's Portfolio

A modern, high-performance portfolio website built to showcase projects, skills, and professional experience. Designed with clean aesthetics, interactive 3D elements, and responsive layouts.

![Portfolio Preview](public/preview.png) *(Preview placeholder)*

## 🌟 Features

- **Next.js App Router**: Utilizing the latest React features for optimal performance and SEO.
- **Tailwind CSS**: Beautiful, responsive, and customizable styling.
- **Framer Motion**: Smooth, hardware-accelerated animations and page transitions.
- **Responsive Design**: Flawless experience across desktop, tablet, and mobile devices.
- **Firebase Hosting**: Deployed globally with Firebase for fast, secure delivery.

## 🚀 Tech Stack

- **Framework:** Next.js 16 (React 19)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Deployment:** Firebase Hosting

## 🛠️ Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📦 Building for Production

To create an optimized production build:

```bash
npm run build
```

This will output the static files to the `out` directory, which can then be deployed to Firebase or any static hosting service.

## 🌐 Deployment

This project is configured for Firebase Hosting. To deploy:

```bash
npx firebase-tools deploy --only hosting
```
